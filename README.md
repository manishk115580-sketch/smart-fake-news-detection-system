# SMART FAKE NEWS DETECTION SYSTEM

## Project Overview
The Smart Fake News Detection System is a Machine Learning-based application designed to classify news articles as Fake News or Real News using Natural Language Processing (NLP) techniques.

The system uses TF-IDF Vectorization and Machine Learning algorithms to analyze news text and predict its category.

## Dataset Description
The project uses the Fake and Real News datasets.

- Fake News Records: 23,481
- Real News Records: 21,417
- Total Records: 44,898

## Machine Learning Algorithms
1. Logistic Regression
2. Multinomial Naive Bayes

## Model Performance

| Algorithm | Accuracy |
|---|---:|
| Logistic Regression | 99.03% |
| Multinomial Naive Bayes | 94.22% |

Note: These results are specific to the selected dataset and test split. They do not guarantee real-world news verification accuracy.

The project includes a Streamlit-based interface where users can enter news text and receive a model prediction.

## Limitations
- Predictions depend on the quality of the training dataset.
- The model may misclassify unfamiliar topics.
- It does not independently verify news facts or sources.
- Human fact-checking is still important.
